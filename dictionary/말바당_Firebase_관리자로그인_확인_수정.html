🌊 말바당 관리자 로그인 확인

최초 관리자의 Google 계정을 Firebase에 등록하기 위한 테스트 페이지입니다. 이 페이지는 Firestore 데이터를 읽거나 수정하지 않습니다.

로그인 전입니다.

로그인 확인 완료

Firebase Console → Authentication → 사용자에서 같은 계정이 등록되었는지 확인하세요.

로그인한 이메일
사용자 고유 ID (UID)

UID 자체는 비밀번호가 아니지만, 관리자 승인 정보를 공개 게시판에 올리지 않는 편이 좋습니다.

학교 프로젝트에서 승인된 본인 계정만 사용하세요. 이 테스트 파일에는 비밀번호나 관리자용 비밀키가 포함되어 있지 않습니다.
